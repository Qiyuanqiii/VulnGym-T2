## 尚存错误与质量问题

### Flowise：模型工具参数 JSON 语法错误

第 218 次累计生成请求（本输入第 12 次），`code=deepseek_response_invalid_json`，`stage=self_review`，`phase=parse_completion_json`，`failure_kind=format`。已收到合法外层响应和用量，函数为 `submit_annotation`；参数解析报 `Expecting ',' delimiter`，第 1 行第 5568 列，参数文本长度为 5567 字符。服务返回 `finish_reason=tool_calls`，并非 `length`；因此不将它写成已经证明的输出 token 上限截断。

解析层判断来自现有账本的净化诊断和本地解析器代码回读；公开 actions 单独只足以确认错误码与自查阶段。无 refusal、无未结束请求，既不是权限拒绝，也不是网络断线。按原计划不重试此输入，只执行当时尚未开始的 Langflow。未猜补 JSON、未删除保护检查。

### Langflow：两个失败的本地读取

`list_files(HEAD)` 返回 `commit_unavailable`；另一 `read_file` 返回 `source_file_unavailable`。它们如实计为 2 项 tool / pipeline 错误，未被判成成功读取。流程之后仍完成自查，但不能用退出 0 掩盖这两次读取失败。
