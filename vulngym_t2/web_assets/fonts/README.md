# Local UI font

`jetbrains-mono-latin-wght-normal.woff2` is the unmodified Latin, normal-style,
variable-weight (100–800) JetBrains Mono font from the locally installed
`@fontsource-variable/jetbrains-mono` version 5.3.0 in the user's TraverseBoard
reference project. It is 40,404 bytes. No network font service is used.

Copyright 2020 The JetBrains Mono Project Authors.
The full SIL Open Font License 1.1 accompanies the font in `OFL.txt`.
Upstream project: https://github.com/JetBrains/JetBrainsMono

Chinese characters use the installed Microsoft YaHei UI / Microsoft YaHei
system fonts. No Microsoft font files are copied or redistributed. Other
unsupported characters use the platform fallback fonts. Code ligatures are
disabled to keep operator glyphs individually readable.
